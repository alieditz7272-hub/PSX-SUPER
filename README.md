# NH PSX Super Analysis

Fresh GitHub Pages PWA following the locked master workflow.

## Files
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- assets/icon.svg
- NH-PSX-Super-Analysis-WORKFLOW.md

The interface intentionally does not expose feed/source names, formulas, backend settings or debug information.

Market data is fetched at runtime from PSX-compatible public endpoints. If a feed is unavailable, the app shows unavailable data rather than fabricating values.
